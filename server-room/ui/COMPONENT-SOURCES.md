# Current component selection: 21st.dev only

The interface uses components selected from these 21st.dev catalogue entries:

- Button: https://21st.dev/@shadcn/components/button
- Tooltip: https://21st.dev/@shadcn/components/tooltip
- Dropdown Menu: https://21st.dev/@shadcn/components/dropdown-menu
- Toggle Group: https://21st.dev/@shadcn/components/toggle-group

These entries are authored by shadcn. 21st.dev is a component catalogue, not a
separate underlying primitive library. Its component-code view requires an
account. The implementation uses the corresponding author's public MIT-licensed
upstream source. No gated source was accessed or copied.

Public upstream: https://github.com/shadcn-ui/ui/tree/main/apps/v4/registry/new-york-v4/ui

Radix supplies accessible focus, keyboard and menu behaviour. Project CSS adapts
the styling. The MIT licence is retained in components/SHADCN-LICENSE.txt.
React and Lucide remain framework/icon dependencies.

Aceternity's tab treatment and React Bits CountUp are no longer used. Their source
and the Motion dependency were removed. Counts use plain formatted text. Blender
assets, 3D animations, simulation logic and datasets are unchanged.
