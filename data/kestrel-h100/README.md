# NLR HPC Kestrel Jobs Data

Source: https://data.nlr.gov/submissions/302
DOI: https://doi.org/10.7799/3023270
Retrieved: 2026-11-08

The ZIP contains the full anonymised Kestrel job dataset in Hive-partitioned Parquet format, covering August 2023 to December 2025. It includes CPU and GPU jobs; H100 jobs use the `gpu-h100` partition.

Files:
- `esif.hpc.kestrel.job-anon.zip`: original dataset archive.
- `datacard.md`: original dataset documentation.
- `LICENSE.html`: complete licence notice saved from https://data.nlr.gov/node/302/license. Keep this notice with all copies of the data.
- `manifest.json`: source URLs, file sizes, and checksums.

Do not attempt to identify individuals from hashed fields. Credit DOE/NLR/ALLIANCE in publications that use the data, as required by the licence.

Published archive MD5: `8f1d3be1cbe6345ef45e658a783c2aa0`.
